# Overview ruler: метки на полосе прокрутки

Статус: `[ ]` — заведено 2026-10-22 при планировании этапа 2 [OpenPerformance.md](OpenPerformance.md).

Человек хочет видеть все вхождения слова под курсором «в маркерах» — на большом файле подсветка
во вьюпорте без обзора всего файла почти бесполезна. Эталон — overview ruler редактора VS Code:
декорации с `overviewRuler: { color, position }` рисуются метками на вертикальной полосе прокрутки
(вхождения — `editorOverviewRuler.wordHighlight*Foreground`, совпадения поиска, ошибки и
предупреждения, git-изменения, курсор). У нас есть только типы API
(`DecorationRenderOptions.overviewRulerColor` в `vscodeTypes.ts`/`wireTypes.ts`), отрисовки нет.

- [ ] Слой меток на полосе прокрутки редактора: строка файла → ряд полосы, наложение по приоритету
  источника, цвета — токены `editorOverviewRuler.*` темы.
- [ ] Источники: вхождения (после этапа 2 — уже вне пути кадра), Find, маркеры Problems, QuickDiff,
  `overviewRulerColor` декораций расширений.
- [ ] Цена на `xlarge`: метки считаются по отсортированным диапазонам за O(совпадений) один раз на
