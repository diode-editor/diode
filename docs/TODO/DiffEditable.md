# Editable live diff — дифф «без компромиссов» на двух настоящих редакторах

**Статус: сделано (PR-1…PR-6).** Дифф-вкладка — композиция двух настоящих
редакторов (`DiffEditorPane2`): стороны редактируются прямо в диффе
(shared/owned/snapshot-источники), живой пересчёт по правкам (debounce 200),
undo/find — бесплатно от редактора; view zones и внешние декорации в
`EditorElement`; side-by-side с авто-inline на узкой панели (зоны-призраки,
порог 100 колонок с гистерезисом) и «Diff: Toggle Inline View»; «Diff: Revert
Hunk»; «Compare New Untitled Text Files»; автопересчёт снимков по сдвигу HEAD
(`DiffSnapshotRefreshContribution`). Старая рисованная смотрелка
(`DiffViewElement` + синтетические документы) удалена. История решений — в git;
приёмочный чек-лист — [DiffViewer.md](DiffViewer.md).

## Follow-up'ы и осознанные люфты

- [ ] **Кликабельные стрелки revert на ганках** (как в VS Code) — нужен hit-test
  колонки гуттер-маркеров в `EditorElement`; сейчас revert — только командой
  «Diff: Revert Hunk» по каретке.
- [ ] **Original-номера строк у зон-призраков в inline** — VS Code показывает их
  отдельной колонкой; у нас гуттер зоны пуст. Добавить, если попросится.
- Режим `auto` (side-by-side/inline по ширине) после первого тумблера вернуть
  можно только сбросом стейта `DIFF_VIEW_MODE_STATE` — осознанный люфт.
- Find идёт по активной стороне (в VS Code — два независимых виджета); матчи,
  как везде у нашего find, статичны до следующего пересчёта.
- Снимочная сторона «(on disk)» (Compare with Saved) не освежается сама —
  `file:` событий не даёт; освежает повторный вызов команды.
- Сплит дифф-вкладки дублем не делится — новая группа открывается пустой
  (см. follow-up'ы [EditorGroups.md](EditorGroups.md)).
- `DiffViewModel.rows` остался без потребителя (покрыт своими юнитами) —
  чистка отдельно.
