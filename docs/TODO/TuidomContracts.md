# Контракты ядра tuidom: аудит зрелости и его правила

Итог архитектурного аудита (2026-07-27) перед выносом tuidom в отдельную
библиотеку. **Все найденные нестыковки (Н1–Н8) закрыты (2026-08-01)** —
подробности решений живут в ADR-доках, здесь остались указатели. Документ
сохранён как страж, пока tuidom живёт в этом репозитории: фильтр «что считается
нестыковкой», проверенный список аддитивного и правило, куда записывать решения.
Найдёшь новую нестыковку — заводи её здесь по тому же фильтру.

## Фильтр аудита

**Нестыковка** — место, где модель противоречит сама себе или где молчаливо
принятое решение вклеено в сигнатуры/семантику так, что потом его не сменить
без слома всех клиентов. Отсутствующая возможность, добавляемая аддитивно
(новое поле с дефолтом = старое поведение), нестыковкой **не является**.

## Что аддитивно (проверено по коду, делается без слома)

Чтобы не пересматривать заново — будущие фичи, добавляемые обычным порядком:

- **Multi-fill с весами в HFlex/VFlex** — `width` уже размеченное объединение
  `fixed|fit|fill`; добавить `weight?` в вариант `fill` — правка внутри двух
  файлов. Задача уже есть: [README.md](README.md), «#6».
- **`gap` во flex-контейнерах** — `{ gap: 0 }` по дефолту = сегодняшнее поведение.
- **Выравнивание по поперечной оси** — union `number | "fill"` расширяется
  вариантами `"start" | "center" | "end"`; обработать обязаны только сами
  flex-элементы.
- **`disabled`-флаг** — повторяет механику `hidden` (пропуск в Tab-обходе и
  хит-тесте); визуальная часть теперь выражается состоянием стиля
  (`setStyleState("disabled")` + when-вариант, см. [STYLES.md](../STYLES.md)).
- **padding/border как обёртки** (`PaddingContainerElement`) — законная модель
  (так устроен Flutter); толщина рамки именована (`BORDER_THICKNESS`, Н7),
  формулы готовы к появлению модели отступов.
- **z-index** — числовой z-index не нужен: перекрытие решают порядок детей и
  слои (`OverlayLayer`); понадобится — вводится сортировкой в одном месте
  (обе стороны Н6-протокола читают один список).
- **`list.hoverForeground`** — hover списков не меняет fg; токен добавляется
  аддитивно (см. STYLES.md «известные сдвиги»).

## Фундамент, прошедший проверку

Трогать не надо: событийная модель (capture/target/bubble, `stopPropagation`),
владение деревом после #214 (производные `getRoot`/`globalPosition`, `hidden`,
`validateTree`), координаты (единственная хранимая величина — `localPosition`),
конвенция intrinsic-размера (все переопределяющие сообщают внешний размер,
включая insets).

## Решения Н1–Н8 (все закрыты, где записано)

Правило: решение по контракту ядра живёт в ADR-доке ([LAYOUT.md](../LAYOUT.md),
[STYLES.md](../STYLES.md)), не в коде и не здесь; сюда — только указатель.

- **Н1. Контракт `performLayout`** (2026-07-28) → LAYOUT.md «Контракт
  performLayout». Flutter-модель: constraints обязывают; «меньше выделенного» —
  только под loose родителя; split `layout()`/`performLayout`, геометрическая
  проверка в `validateTree`.
- **Н2. Клип детей** (2026-07-29) → LAYOUT.md «Инвариант вложенности и клип».
  Переполнение нелегально нигде: `Rect(child) ⊆ Rect(parent)` без исключений;
  попапы живут в `OverlayLayer` реперентингом, а не рисованием за якорем.
- **Н3. Один источник цвета** (2026-08-01) → [STYLES.md](../STYLES.md) целиком.
  Каскад — единственный источник на отрисовке; состояния разрешает ядро
  (when-варианты); цвета — токены-переменные, палитру темы кладёт одна точка
  (`applyThemeVars`). Попутно квик-пик впервые темизирован.
- **Н4. Уведомление об укоренении** (2026-07-30) → LAYOUT.md «Подключение к
  дереву». Хуки `onDidConnect(root)`/`onDidDisconnect()` — пропагация события
  по поддереву; `getRoot()` остался производным.
- **Н5. `item.position` в OverlayLayer** — закрыт вместе с Н2: слой читает
  `child.localPosition`, `item.position` — только вход сессии.
- **Н6. Один источник порядка** (2026-07-30) → LAYOUT.md «Хит-тест: один
  источник порядка». `elementFromPoint` — финальный шаблон, кастомизация только
  через симметричные `hitTestChildren`/`hitTestSelf`.
- **Н7. Толщина рамки** (2026-08-01) → LAYOUT.md «Толщина рамки (Н7)».
  `BORDER_THICKNESS` (`tuidom/dom/borderStyle.ts`) во всей арифметике
  размеров/смещений; рисование глифов литеральное осознанно.
- **Н8. `tabIndex` → `focusable: boolean`** (2026-07-30). Числовой порядок
  отвергнут: он был бы вторым источником порядка против инварианта «Tab-обход =
  порядок детей» (в вебе `tabindex > 0` — признанный антипаттерн).

## Связь с выносом tuidom

Критерий готовности к выносу — закрытые контракты ядра — **выполнен
(2026-08-01, Н1–Н8)**. Остаток пути — [TuidomExtraction.md](TuidomExtraction.md)
(развязка stories/бенчей от `src/`, CI-граница с покрытием тестов). Календарные
критерии («N недель без breaking») не используем — тишина будет следствием
закрытых контрактов, а не сигналом.
