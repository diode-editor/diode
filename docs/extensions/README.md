# Матрица расширение × API

Отвечает на два вопроса: какой член API нужен скольким расширениям и каким расширениям чего не хватает. Правила и классы — эпик #912. Читать — [api-matrix.generated.md](api-matrix.generated.md).

| Файл | Что это | Кто пишет |
|---|---|---|
| `survey.json` | обзор: id, версия, скачивания, использованные члены, ключи `contributes`, `activationEvents`, дата | `node scripts/ext-survey.mjs` (нужна сеть, в гейтах не запускается) |
| `api-matrix/<namespace>.json` | класс каждого члена `vscode.d.ts`; типы верхнего уровня — в `types.json` | руками, по правде кода |
| `api-matrix.generated.md` | таблица для чтения | `npm run api-matrix`, руками не правится |
| `api-confirmed/<id>.json` | отметка «подтверждён»: `{ "members": [...] }` | только из журнала вызовов: `npm run api-matrix -- --update-confirmed` |

Отметка «тест» выводится сама: тег `[api:window.showTextDocument]` в названии запускаемого теста (`test`, `it`; комментарий, строка, `test.skip` и `test.todo` не считаются) или зелёный тест эталона из `e2e/api-conformance/memberMap.json`. Тег с несуществующим членом роняет гейт.

Гейт `npm run api-matrix -- --check` (static в CI) падает, если у члена нет класса, класс висит на несуществующем члене или сгенерированный файл отстал. Сеть ему не нужна.

## Классы

`A`, `B`, `C`, `X` — как в эпике. `ok` — наше дополнение: у члена нет известного пробела. Это не отметка «закрыт»: закрытие выводится из теста и журнала.

Первичная разметка: объявлен в `vscode.d.ts` — `ok`, не объявлен — `B`; поверх этого семейства типов и отдельные члены по коду и задачам эпика. Интерфейсные поля размечены по семействам, а не прочитаны по одному: нашёл расхождение — правь строку.

## Что обзор видит и чего нет

- Разбор по AST с учётом областей видимости: `require("vscode")` и его минифицированные имена, модули webpack и esbuild, обёртки `__toESM`/`__importStar`, деструктуризация, ESM-импорт. Код не исполняется.
- Разбираются все `.js` в `extension/`, включая `node_modules`: `vscode-languageclient` дёргает API от имени расширения.
- Член, полученный через значение (`editor.document.getText()`), синтаксически с API не связан, поэтому у членов интерфейсов использование всегда 0. Ноль значит «не найдено», а не «нет». Доля бандлов, где API не нашёлся, — в шапке матрицы.
- Расширение без единого найденного члена не попадает в рейтинг расширений: нулевой разрыв читался бы как «всего хватает». Расширение с `contributes.iconThemes` не предлагается: иконки тем — класс C, а по членам API этого не видно.
- В обзор кроме топа всегда входят записи нашего реестра: на них проверяются смоуки магазина, даже если они не в топе.
- Кэш — `~/.cache/diode/ext-survey`: `.vsix` удаляется сразу после разбора, остаётся результат на версию. Поменял то, что находит анализатор, — подними `ANALYZER_VERSION` в `scripts/ext-survey.mjs`.

## Журнал вызовов

`DIODE_API_TRACE=<файл>` включает журнал в ext host; без переменной оверлей не оборачивает ничего и файла нет. Формат — JSON-строки, строка — прирост: `{"extension":"pub.a","member":"languages.registerCompletionItemProvider","kind":"invoked","method":"provideCompletionItems","count":1}`. Читатель суммирует `count`; новый факт пишется сразу, повторы — раз в 250 мс и на выходе. Сбой записи один раз уходит в лог и выключает журнал, расширение его не видит.

| `kind` | Что значит | Подтверждает член |
|---|---|---|
| `call`, `read` | вызов функции и чтение свойства неймспейса | да |
| `registered` | вызов `register*Provider` | **нет**: регистрация не использование |
| `invoked` | редактор вызвал метод провайдера (`method`) | да |
| `field` | провайдер заполнил поле ответа (`CompletionItem.sortText`) | да |

Границы:

- Только неймспейсы. Чтение верхнего уровня (`vscode.Position`) не пишется: ESM-шим и `__importStar` читают все экспорты при импорте, такая запись ничего не значила бы. Поэтому `types.json` журнал не подтверждает.
- Поля ответа — только у `provideCompletionItems` и `resolveCompletionItem`: для остальных провайдеров нужна таблица типов результата. Смотрим собственные поля без вызова геттеров; поле с геттером на прототипе не видно, ответ в чужом thenable (не нативный `Promise`) не разбирается.
- Метод провайдера с именем `onDid*` — событие, а не вызов редактора, `invoked` не пишет.
- Журнал фиксирует факт вызова. Был ли результат правильным, проверяют тест и кадр.

Смоук `e2e/marketplace/` пишет журнал сам и оставляет `e2e/marketplace/api-trace/<id>.jsonl` только зелёным; красный прогон удаляет и журнал прошлого зелёного. CI выкладывает этот каталог артефактом `api-trace-<ОС>` при прогоне e2e. `npm run api-matrix -- --update-confirmed` переносит вызовы самого расширения в `api-confirmed/<id>.json` и пересобирает таблицу; расширение без журнала сохраняет прежние отметки. В обычном `npm run api-matrix` и в `--check` журналы не читаются.
