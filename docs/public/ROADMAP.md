# Роадмап

diode — **альфа**. Редактором можно пользоваться, но поверхность API и набор инструментов ещё
растут. Эта страница — куда идём и в каком порядке.

## Цель

Полная поддержка API расширений VS Code — везде, где она имеет смысл в терминале. Языковые и
тулинговые расширения — да; webview-поверхности — не будут поддержаны (требуют браузера).
Измеримый прогресс — в [матрице готовности](API-COVERAGE.md).

## Ближайшее

Первый выпуск привязан к одному кадру: терминал, который выглядит и ведёт себя как VS Code —
тема, подсветка, живой language server, автодополнение. Всё, что ниже, нужно, чтобы этот кадр
был правдой на любом файле и на любой машине.

- **Старт под защитой.** Лестница старта (см. [бенчмарки](BENCHMARKS.md)) закрепляется
  перф-порогом в CI, чтобы цифра не уплывала по мере роста фич.
- **Большие файлы без пауз.** Фоновая токенизация кусками вместо синхронной на открытии и
  режим «большой файл», который гасит дорогие фичи выше порога размера.
- **Длинные строки.** Кеш отображаемой строки, ленивое окно по видимым колонкам, переход по
  клику за порог отрисовки, настраиваемый порог `editor.stopRenderingLineAfter`.
- **Большие деревья файлов.** Фильтр по `.gitignore`, индекс по ключу вместо линейных сканов,
  бюджет на кадр в поиске, инкрементальная сверка от событий файловой системы; следом —
  нативный watcher вместо JS-обхода.
- **Сравнение с другими редакторами.** Таблица vim · neovim · neovim+дистрибутив · helix ·
  diode, снятая одним прогоном по опубликованной методике.
- **Установка одной командой** поверх готовых single-binary сборок.
- **Языки из коробки.** К TypeScript/JavaScript и Python в магазине добавляется Go.

## Дальше

Без обещания сроков, в порядке, который сейчас кажется правильным.

- **Рост поверхности API расширений** по [матрице готовности](API-COVERAGE.md): темы и
  иконки от расширений, language configuration, snippets, configuration, views.
- **Больше языков в магазине**: Rust, C#, дальше по спросу.
- **Semantic tokens из LSP** поверх TextMate-подсветки.
- **Точечная перерисовка кадра** (damage-tracking): hover, оверлеи, клип цикла строк — экономия
  на каждом кадре, которую пользователь не видит, но чувствует на слабом канале.
- **Piece tree** как хранилище документа: файлы на сотни мегабайт, дешёвые снапшоты и undo.
- **Редактор для агента**: MCP-сервер поверх extension host — language server как инструмент
  агента, а не regex.

## Не будет

- Webview и UI-heavy расширения — потолок терминала, by design.
- GUI-версия — diode живёт в терминале.
