# Публичная документация

Каталог страниц, на которые ссылается сайт [diode-editor.github.io](https://diode-editor.github.io/).
В отличие от остального `docs/` (внутренняя разработческая дока), эти страницы пишутся для
пользователя и читаются с лендинга.

- [BENCHMARKS.md](BENCHMARKS.md) — скорость старта: лестница, сравнение с другими редакторами, методика
- [BENCH-OPEN.md](BENCH-OPEN.md) — открытие файла: до текста и до подсветки, от 100 строк до 500 МБ; обновляется PR-ами джобы `bench.yml`
- [API-COVERAGE.md](API-COVERAGE.md) — матрица готовности API расширений VS Code
- [ROADMAP.md](ROADMAP.md) — статус «альфа», цель и порядок движения

Правила каталога:

- **Цифры и статусы не пишутся руками по памяти.** Бенчи — только снятые по методике из самой
  страницы; матрица — генерация из `vscode.d.ts` (активная поверхность = раскомментированные строки).
- **Потолок называем вслух.** Графа «не будет by design» — обязательная часть матрицы, проигрыш
  голому vim по старту — обязательная часть бенчей.
- Тон — спокойный и проверяемый: каждая цифра воспроизводима, каждый статус выводится из исходников.
