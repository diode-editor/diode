# Diode Sample Language

Синтетическое расширение для магазина: доказывает, что запись `kind: "native"` —
наш собственный `.vsix`, который мы сами и раздаём, — доезжает до пользователя и
работает. Никакой полезной функциональности здесь нет и не планируется.

Покрывает **декларативный** путь расширения (вклад языка и грамматики, без `main`
и без extension host'а) — в отличие от `test.tab-setter`, который проверяет
рантайм-путь через subprocess. Наблюдаемый эффект: файл `.diodesample` получает
язык `Diode Sample`, и это видно в статус-баре.

Публикация (после правки — заново):

```
node scripts/pack-vsix.mjs e2e/marketplace/sample-extension <site>/artifacts/test.sample-lang-0.0.1.vsix
```

затем в репозитории сайта обновить `extensions/test.sample-lang.json` (версия,
`sha256`, `size`) — печатает их сам упаковщик.
