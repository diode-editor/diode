   ```
   gh pr merge <номер> --merge
   ```

3. Подтяни ствол в основном дереве: `git -C <корень> fetch origin && git -C <корень> merge --ff-only origin/main`.
4. Открой следующую итерацию: `node scripts/iteration.mjs start` (номер возьмётся следующим по порядку).

   - `git worktree remove .claude/worktrees/iteration`;

**Не влилось** (красные проверки, конфликт со стволом, PR закрыт) — ничего не чини: опубликуй `релиз`
с тем, что именно мешает, подними флаг и заяви результат **`не влилось`**. Итерация вернётся сборщику.
