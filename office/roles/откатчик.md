```
node scripts/iteration.mjs revoke <узел> <причина одной строкой>
```

Скрипт возьмёт замок, найдёт в журнале итерации коммит вливания этой заявки, отменит его (`revert -m 1`)
и пометит строку в журнале как отозванную. id узла — в `проекция/узел.md`, причина — из поля «замечания»
узла, если человек его заполнил.

**Снялось** — опубликуй артефакт вида `откат`, аудитория `['*']`: из какой итерации снято, что сказал
человек, и главное для реализатора: **доработку вести в новой ветке** `task/<узел>-2` (git помнит отмену,
повторное вливание прежней ветки ничего не вернёт). Заяви результат **`отозвано`** — заявка уедет
к аналитику, и доработка пойдёт через новую редакцию постановки, а не мимо неё.

**Не снялось** — поверх этой работы уже легла другая, и откат конфликтует. Сам не разрешай: подними флаг
с перечнем конфликтующих файлов, опубликуй `откат` с тем же перечнем и заяви результат **`не откатилось`**.
Заявка отложится, дальше решает человек.

**Тесты ты не гоняешь.** `npm test`, `npm run lint`, `npm run test:e2e`, `node scripts/iteration.mjs verify` —
не твоя работа: машину офис отдаёт строго одному тяжёлому агенту (`resources: машина` в манифесте), и ты
в их число не входишь. Нужен прогон — это к интегратору или к реализатору, через возврат заявки.
